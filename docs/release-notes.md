One lift. No personal space.

Fight through four stops in a three-square-metre elevator, from the lobby to the building manager on the roof. Original animated pixel art, punch combos, sweeping kicks, dodges, wall slams, a rechargeable burst, synthesized music, touch controls, and standard controller support.

**Play online:** https://mattias800.github.io/lift-off/

**Play offline:** download `lift-off.html` below and open it in a modern browser. No installation or server required. All assets, fonts, and license notices are included in the file.

**Keyboard:** WASD/arrows to move · hold J to punch · K to kick · L to dodge · Space to burst · Esc/P to pause. Enter starts or replays.

Built with TypeScript, Canvas 2D, and Web Audio. Source and development instructions are in the repository. Includes simulation tests and a complete browser playthrough using real keyboard input.
